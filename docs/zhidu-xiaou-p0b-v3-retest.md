## 三例逐项核对

### AUTO-01

v2 问题句：“只是说这时它足以支持选择。”它把必要限制局部变成了充分保证。

v3 明确说：“它没有说只要目标明确、误差可接受，计算就一定足够”。同时正确保留“不反对计算”和“暂时不能量化不等于无价值”，没有宣称其他场景计算全部无用。

本样本的条件方向问题已解决。直接引文可核对、没有虚构前后文；不足是同一句先转述再引用，末段又归纳，仍可更紧凑。

### PLAIN-02

v2 曾输出 `book_text`、材料分类和目录信息清点；v3 使用自然中文，没有这些内部字段，也没有声称看过额外前后文。

主要结论正确：迟到减少可观察，但不能确认读书角是原因，也未证明公交必然有效或读书角无效。问题在中段“明确否定了‘读书角导致迟到下降’这个结论”过强。结合首尾看，模型可能只是想说否定已证实的断言；但孤立读该句容易被理解为因果关系已被证伪，应改为“没有足够依据确认”。本轮仅记录，不改模型输出或源码。

自然表达专项有改善；仍重复解释及全文引用，语义强度风险尚未消除。

### ARGUMENT-04 固定历史纠错

v3 开头“不是，我上一条说错了，先更正”，紧接准确引用“尚不能确定水站单独造成全部改善”。没有继续维护错误 seed，没有无关例子、分母或假称结合前后文。

相比 v2 的多个栏目，v3 改为自然段，输出 Token 从264降到184。但仍出现“原文明确排除了这个结论”：应否定“已经证明”的断言，不能排除实际因果解释的可能性。后文“不能确认”是正确的，却没有完全消除开头的歧义。前提一/前提二和结尾再次认错仍有重复。

先纠错再给依据与去模板目标已表现出来；措辞边界仍需小修。
