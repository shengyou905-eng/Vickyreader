没有修改数据库、后端、模型 Prompt、IAP、Pro、Obsidian、明台、随心记或五种免费解释模式。没有新增依赖、修改全局主题、连接真实业务数据、调用付费模型、构建发布、部署、提交或推送。正式回望入口仍关闭；不进入 B2.4c。

## 3. 视觉规范与复用

复用现有 AppTheme 字体、AppPalette 强调色和 Flutter Material 图标。未引入新的字体包、图标包或设计系统。新增样式仅作用于回望页面。

| 元素 | 规范 |
| --- | --- |
| 页面标题 | 22，600 字重，左对齐 |
| 章节标题 | 20，600 字重，1.4 行高 |
| 书籍信息 / 条目标题 | 17 / 16，适度加粗 |
| 正文 | 15，1.6 行高，字距 0 |
| 原文预览 | 14，1.6 行高 |
| 说明 / 引用 | 13 / 12，1.6 行高 |
| 主按钮 | 15，600 字重，至少 48 高；系统字体缩放后自然增高 |
| 水平边距 / 内容宽度 | 20；最大阅读容器 640 |
| 间距 | 以 8/12/16/20 为主要刻度，不依靠大空白堆叠层级 |
| 圆角 | 材料重复条目、主按钮及输入框 12；Chip 8 |

浅色页面背景 `#FAFAF7`、正文 `#292D32`、辅助说明 `#666E77`；辅助色选择比参考灰稍深，以保持小字号可读性。主按钮使用 `#89CFF0`，配深色文字 `#243C4A`。低干扰交互沿用主题 primaryDeep，避免所有文字都使用高亮蓝。

深色分支取宿主 ColorScheme 的 surface/onSurface/onSurfaceVariant，强调色使用浅蓝；没有将浅色背景或浅灰正文直接搬入深色。测试注入 ThemeData.dark() 验证组件，不宣称全应用已新增深色主题能力。

统一复用页面内 `_style`、`_heading`、`_caption`、`_status`、`_command`、`_primary`、`_bookHeader`、`_bottomActions` 和 `_refs`。状态说明保留完整错误信息；错误提示带 liveRegion。小型引用保持至少 44 的触控高度，不以缩小触控面积换取紧凑外观。

## 4. 逐页改进

### 材料选择

- 书籍名称、图标和实际材料数量形成一个紧凑信息区，只通过本机已授权 bookId 关联，不按名称猜配。
- 类型筛选改为单行可横向滚动 Chip，避免窄屏强行折行；选中状态以浅色底与细边框表达。
- 阅读记录采用轻量条目，类型、原文与用户提问区分字号和颜色；不同阅读行为仍独立勾选。
- 按本轮新要求，较长原文（超过 160 字）默认展示最多六行，保留全文并可展开/收起；短片段不截取。没有修改阅读器本来的原文预览。
- 保留追问全部、空选择、部分选择及不可用原因。确认按钮移至 SafeArea 底栏；刷新和换书保持次级位置。

### 范围确认

- 展示书籍、服务器确认的记录和追问数量，并在本机材料仍有效时展示类型数量。
- 明确保留“仅依据已确认的阅读记录”“不代表整本书”“所选材料交给云端 AI”“随心记不参与”。没有折叠到不可发现位置，也没有省略隐私说明。
- 生成/恢复查看使用固定主按钮；重新选择保留为次级操作，不修改授权或生成流程。

### 回望详情

- 顶部补充来源书籍信息及范围声明；正文为连续文章，不把每句话放进卡片。
- 一级章节保持知识整理、我的思考、可选继续思考。存在待解决问题时在我的思考之后采用次级标题呈现，数据没有删除。
- 条目标题与正文建立层级；引用缩为低干扰注释链接，保留 AI 推断标记和关系解释。
- 底栏以“继续追问”为主、“保存回望”为次；已保存禁用重复保存。
- “继续查看”仍是原有许可续核操作，移入更多操作，不改许可时长、不自动轮询。
- 反馈、删除、重新选择放在页内展开的更多区；不使用覆盖路由的菜单来规避/误触既有生命周期撤回。长文滚动后展开更多会回到可见位置。
- 删除新增明确确认，可选择保留回望；只有确认后调用原删除方法。没有改后端删除范围。

### 历史

- 简化为书籍、保存/预览/失效状态、实际记录时间和轻量分隔线。
- 移除重复大标题；保留分页、删除及缺少本机书籍时的占位。历史仍无正文缓存。
- 历史删除也需确认；不影响账号切换、来源缺失时的隐私删除能力。

### 证据与专属追问

- 证据使用细引用线、来源分类和章节说明；保留 fragment_only 限制及“未核实完整原书逐字内容”的说明，没有新增伪精准跳转。
- 追问采用克制的“我的问题 / 小U”层级、自然段落、浅底输入区和原有发送/取消/错误行为；不混入普通会话。

## 5. 安全与交互不变量

没有修改 controller、repository、服务端 DTO 或 API。所有请求仍经过原 `_action`、会话、pending、来源确认与许可复核链路。页面仍即时读取可撤回内容，不持久化私人正文副本。

新增的书名展示使用现有本地授权目录；异步返回后先检查原会话，再保留显示用标题；退出、断网或来源变化仍清除。新增更多菜单、删除确认仅存布尔状态/回望 ID，不保存私人正文。

增加的 ScrollController 只负责将页内操作滚到可见位置，不延长展示许可、不发网络请求。反馈表单位于正文之前，避免在长文底部出现不可见的交互。

安全提示、取消、失败、重放、离线占位、授权拒绝、来源变化和历史隔离均保留。没有把 UI 平滑当作绕过安全复核的理由。
